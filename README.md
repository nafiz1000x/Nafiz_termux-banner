# 🎨 Termux Banner Tool

## Developer: Nafiz Sheikh

এই টুলসের মাধ্যমে আপনারা খুব সহজেই Termux-এ নিজের পছন্দমতো Banner Add করতে পারবেন। নিজের নাম, টিমের নাম বা যেকোনো কাস্টম টেক্সট ব্যবহার করে আকর্ষণীয় Banner তৈরি করা যাবে।



📥 Installation
```
git clone https://github.com/nafiz1000x/Nafiz_termux-banner.git
cd Nafiz_termux-banner
bash os.sh
```
